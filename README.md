# 🎓 CampusPulse — The Next-Gen Smart University OS & Campus Super-App
> **Hackathon Ready • Full-Stack Production Prototype • AI Powered**

CampusPulse is an all-in-one unified campus operating system built to eliminate daily student struggles: finding classrooms across massive multi-acre campuses, calculating safe attendance bunk limits, tracking live mess menus with meal ratings, and clearing semester fee dues with instant official digital receipts.

---

## 🚀 Key Presentation Features (The "Wow" Factors for Judges)

1. **📊 Attendance & Safe-Bunk Predictive Engine:**
   - Real-time subject-wise attendance tracking against the 75% university eligibility criteria.
   - **Interactive What-If Simulator:** Let students select future scenarios (*"What if I miss next 2 classes?"*) to calculate exact projected percentage.
   - **Safe-Bunk Advisor:** Algorithmic calculation of the exact number of classes a student can safely skip before dropping into debarment risk.

2. **🗺️ Interactive 2D Campus Map & Block Route Navigator:**
   - Visual interactive campus layout mapping Academic Blocks (Aryabhatta, Ramanujan, C.V. Raman), Hostels (Mandovi, Shivalik), Mess, Library, and Admin desks.
   - Clickable building nodes with floor-wise room directory.
   - Dynamic animated walking route pathfinder with distance (meters) and estimated walking time.

3. **📅 Smart Timetable Synced with Classroom Locations:**
   - Day-wise academic schedules (Monday to Friday).
   - Dynamic **"Active Session" / "Next Up"** alert with direct one-click classroom location routing.

4. **🍽️ Central Mess Menu & Live Student Food Reviews:**
   - Daily 4-meal cycle (Breakfast, Lunch, Snacks, Dinner) with calorie counts, dietary tags (High Protein, Indori Classic, Chef's Special).
   - Real-time interactive student rating & feedback form with verified student ledger stream.

5. **💳 Integrated Fee Payment Portal & Digital Sealed Receipts:**
   - Transparent ledger: Tuition, Hostel Room, Mess Advance, and Examination fees.
   - FastPay simulated checkout (UPI QR code, Cards, NetBanking) with celebratory confetti.
   - Instant generation of an official **Digitally Signed & Sealed University e-Receipt** with printable/PDF format.

6. **🤖 UniBot — 24/7 Campus AI Copilot:**
   - Multi-lingual interactive campus assistant answering queries about classroom locations, mess menus, fee deadlines, and attendance rules with direct actionable UI cards.

7. **🚨 1-Touch Emergency Campus SOS:**
   - Instant geolocated dispatch to Campus Quick Response Teams (QRT), 24/7 Medical Clinic Ambulance, and Hostel Wardens.

## 🛠️ Tech Stack & Architecture

- **Backend:** Node.js, Express.js RESTful API architecture
- **Frontend:** Vanilla HTML5, Modern Tailwind CSS, Plus Jakarta Sans & Space Grotesk typography
- **Visuals & Icons:** Lucide Icons, Canvas Confetti, SVG Vector Map
- **Deployment:** Zero-config single-command runtime on `http://localhost:3000`
